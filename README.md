# Patient Management Microservices Project

A cloud-ready **Patient Management System** built with **Spring Boot microservices**, **Apache Kafka**, **Docker**, and **Kubernetes**.  
This project demonstrates scalable, loosely-coupled healthcare services with real-world microservice architecture patterns.

---

## 🚀 Features

- **Microservices Architecture**: Independent services for patient management, billing, and more.
- **Event-driven Communication**: Kafka topics for asynchronous messaging between services.
- **Containerization**: Docker for easy deployment and isolation.
- **Orchestration**: Kubernetes for scaling and management of services.
- **REST APIs & gRPC**: Inter-service and client communication.
- **Logging & Monitoring**: Centralized logs and metrics collection.

---

## 📦 Tech Stack

- **Backend**: Java, Spring Boot, Spring Cloud
- **Messaging**: Apache Kafka
- **Containerization**: Docker
- **Orchestration**: Kubernetes (K8s)
- **Database**: MySQL / PostgreSQL (or any RDBMS)
- **API Communication**: REST + gRPC
- **Version Control**: Git + GitHub
